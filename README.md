## 🎯 À propos

**OCTARYS** est un service de support informatique professionnel offrant des solutions à distance et en présentiel dans la région de Trois-Rivières.

### ✨ Services offerts

- 🖥️ **Support à distance** via outils spécialisés
- 🏠 **Interventions à domicile** (particuliers)
- 🏢 **Support entreprises** (PME)
- 🔧 **Diagnostic intelligent** avec IA intégrée
- ⚡ **Réparations rapides** et efficaces
- 🛡️ **Sécurité & Protection** (antivirus, pare-feu)

## 🚀 Technologies

Ce site web utilise:

- **HTML5/CSS3** - Design moderne et responsive
- **JavaScript** - Diagnostic interactif
- **Design Cyber-Électrique** - Esthétique cyan/bleu avec effets néon
- **GitHub Pages** - Hébergement gratuit et fiable

## 🎨 Design

Le design s'inspire de l'identité visuelle **OCTARYS** avec:

- Palette **cyan électrique** (#00D4FF) & **bleu** (#0099CC)
- Accents **dorés** (#FFD700) pour les éléments clés
- Effets **néon** et **glow** pour un look tech moderne
- **Glassmorphism** pour les cartes et éléments UI
- Animations subtiles pour une expérience dynamique
